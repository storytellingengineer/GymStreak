# GymStreak

Duolingo-style consistency and workout tracking app.

## MVP
- Daily gym streak
- Today's workout recommendation
- Workout session with set completion
- Local persistence
- Workout history
- AI Coach foundation
- Widget preview

## Run
npm install
npm run dev

## Roadmap
1. Stable workout loop
2. Recovery-aware recommendation engine
3. Progressive overload tracking
4. Real AI coach
5. Android home-screen widget
6. Notifications and streak freeze
7. Cloud sync and authentication
